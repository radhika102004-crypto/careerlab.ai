# CareerLab AI

A career guidance web app where students try a career before choosing it. Instead of only taking a questionnaire, users complete short, realistic tasks from a role, get feedback on their work, and build a profile of which roles suit them.

This is a front-end prototype built as a BCA major project at JECRC University, Jaipur.

## The problem
Most career tools recommend a career from marks, skills and interests. Students never find out whether they enjoy the actual work. CareerLab AI adds a practical step: do a small piece of the job first.

## Features
- Three-step profile form (about you, interests, how you work)
- Role suggestions based on interests and problem-solving style
- Career experiments for four roles: Software Developer, UX Designer, Digital Marketer and Data Analyst
- Instant feedback with a task score, enjoyment rating and career-fit percentage
- Skill-gap view with suggested next steps for each role
- Jobs page with starter roles and links to search listings
- Career chat that answers questions about the roles and your results
- Portfolio built from completed experiments
- Editable profile, help box, and privacy policy and terms pages
- Dark and light theme, responsive layout, keyboard and screen reader support

## How scoring works
Each task is scored out of 100 with a fixed rubric: 50 points for covering the key ideas, 30 for enough detail and 20 for structure. Career fit is 60% task score plus 40% enjoyment rating.

## Tech stack
- HTML5, CSS3 (Grid, Flexbox, CSS variables)
- Vanilla JavaScript (ES6)
- Browser localStorage for saved data
- Google Fonts (Unbounded and Figtree)

## Run locally
1. Clone the repository.
2. Open the folder in VS Code and install the Live Server extension.
3. Right-click `index.html` and choose "Open with Live Server".

You can also open `index.html` directly in a browser. No install or build step is needed.
